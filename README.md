# Company Search Funnel Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes company-side search and discovery activity for a marketplace platform. The objective is to understand how companies search for jobs and candidates, evaluate search performance, and identify important funnel metrics.

The project focuses on the *Company Funnel* and converts raw event data into meaningful metrics that can support business decisions.

## Objectives

* Analyze company search and discovery activity
* Measure job views and candidate views
* Compare different search sources
* Analyze job categories and regions
* Evaluate candidate-job fit scores
* Monitor search performance and data quality

## Tools & Technologies

* *Excel* – Data Cleaning
* *Python* – Data Analysis
* *Pandas* – Data Manipulation
* *Tableau* – Dashboard & Visualization
* *GitHub* – Project Documentation

## Project Workflow

*Raw Dataset → Excel Cleaning → Python Analysis → Tableau Dashboard → Business Insights*

### Excel Data Cleaning

The raw dataset was cleaned in Excel by identifying duplicate records, handling missing values, standardizing categorical values, validating dates and numeric fields, and checking data quality.

### Python Analysis

Python and Pandas were used to analyze company search activity, funnel performance, search sources, job categories, regions, fit scores, search speed, and data quality.

All analysis outputs were consolidated into a single Excel workbook named *Python Analysis Result.xlsx*.

### Tableau Dashboard

The Tableau dashboard provides a single view of the Company Search & Discovery Funnel, including:

* Total Events
* Job Views
* Candidate Views
* Search Source Performance
* Job Category Analysis
* Region Performance
* Search Speed

## Key Outcome

The project provides a structured view of the company-side discovery funnel and helps identify how search activity moves toward job and candidate views. It also highlights search performance and data-quality indicators that can support better marketplace decisions.
